Everything an editor leaves out.

Your CLIs are already good. What is missing is the layer above them.

01

Real PTYs, not a proxy

Each session spawns the actual engine binary. Resume is the engine's own resume.

02

Many repos, one window

Four-up grids across repos, ⌘K to anywhere. An editor gives you one project.

03

A cockpit per session

Context window, plan usage, the current tool call, todos, git state, review verdict.

04

Agents, not prompts

A named roster with model policy and checks, versioned in .agents/.

05

Its own worktree

Every code-touching run branches into isolation. Your checkout is never touched.

06

Schedules outlive the app

Real launchd jobs on a headless runner. They fire with the app closed.

07

A gate that gates

Blockers file to one inbox and ping your phone. A stalled agent is visible.

08

Local-first, file-shaped

No server, no account, no telemetry. Tickets and runs are files you can diff.

Agents never merge

They ticket, branch, test, implement, open the pull request — and stop. The tooling enforces it; a prompt cannot talk one past the gate.

  1. Ticket
  2. Worktree
  3. Test first
  4. Implement
  5. Review to a bar
  6. You merge

Tickets are markdown with acceptance criteria. GitHub Issues, Linear, or an Obsidian vault drop in as providers.

Install

Take the DMG for the packaged app, or the source route to hack on it. Either way you need at least one engine CLI on your PATH.

Download the app

The packaged desktop build. Apple silicon, unsigned and un-notarized.

  • →Open the DMG, drag TerMinal.app to Applications.
  • →First launch: right-click, then Open, then Open. A double-click will be refused.
  • →Onboarding probes your machine and confirms your projects folder. Both steps are skippable.
$ shasum -a 256 -c SHA256SUMS.txt
Download for macOS Checksums

Build from source

Clones the repo and installs dependencies. Requires bun and git.

$ curl -fsSL https://raw.githubusercontent.com/trevormil/TerMinal/main/install.sh | bash
  • →Clones to ~/TerMinal, or pass a path to change it.
  • →Installs dependencies and rebuilds the native terminal against Electron.
  • →Then bun run dev to launch it.

Dev works on Linux minus local schedules. Packaging, launchd, and the editor handoffs assume macOS.
